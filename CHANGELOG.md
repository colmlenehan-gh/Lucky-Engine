# Changelog

## 0.1.0 beta

Initial experimental Lucky package for Windows x64.

- Added a custom black-and-white project launcher and editor.
- Added an inverse light theme and persisted editor preferences.
- Added 2D/3D scene previews, primitive editing, transforms, materials, selection, undo and redo.
- Added Blank, Showcase and playable 2D Platformer templates.
- Added project persistence, generated Godot scenes, validation, autosave and scene snapshots.
- Added asset importing, 2D image sprites, basic GDScript editing and per-object script attachment.
- Added project renaming/cloning, an optional example gallery and runtime output capture.
- Added project run/stop and portable Windows runtime-folder export.
- Added an embedded chat sidebar with a Codex app-server adapter, ChatGPT subscription sign-in, provider model discovery, supported reasoning/Fast modes, file/image attachments, HTTPS MCP configuration and server discovery.
- Added the official Codex app-server connector as an optional offline setup component.
- Added Windows setup packaging and source/build materials.

This release runs a new Lucky editor on the unmodified Godot 4.7.2 runtime. It does not include a source-compiled fork of the upstream editor. Other AI providers, complete upstream editor coverage and broad platform exports remain future work. No comparative performance claims are made.
