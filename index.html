01 — THE IDEA

One place for
the whole scene.

Lucky is an experimental Windows scene editor and launcher built on Godot, with an integrated AI workspace.

Start with a blank canvas or an example. Arrange objects, tune transforms, import assets, write scripts, then run your project — all from a deliberately monochrome workspace.

02 — THE WORKSPACE

Small tools.
Room to build.

Core workflows for making and testing a scene, without pretending to be a complete replacement for every editor subsystem.

01 / CREATE

Start anywhere

Choose Blank, Showcase, or a playable 2D Platformer template. Projects are created in their own dedicated folders.

02 / SHAPE

2D + 3D scenes

Work with 2D sprites, shapes and labels, or 3D primitives. Move, rotate, scale, filter, duplicate and reorder objects.

03 / ITERATE

Save, run, repeat

Save a portable Lucky manifest, use snapshots, edit GDScript, and run or stop projects with the included runtime.

04 / ASSIST

AI, in the flow

Connect an optional Codex app-server or compatible executable for streamed chat, supported attachments and MCP discovery.

03 — GETTING STARTED

From download
to first scene.

The Windows installer includes the game-engine runtime. The optional AI connector is a separate, larger component.

  1. 01
    Get the latest release

    Download the Windows x64 installer from GitHub Releases.

  2. 02
    Create a project

    Choose a template and a parent folder. Lucky creates a dedicated project directory.

  3. 03
    Build your scene

    Use Add, Inspector and Save to shape the scene, then press Run to launch it.

Beta note

Lucky is experimental. General import of existing Godot projects, advanced editor systems, automatic AI project-file changes, and cross-platform native exports are not implemented in this beta. The installer is currently unsigned.
